# Ejercicio Nro: 3

## Enunciado
**¿Qué ventajas y desventajas tienen los diagramas UML?**
* **Ayuda:** Se puede relacionar con los planos de la Ingeniería tradicional.

## Resolución
* **Ventajas:** Permiten visualizar y estructurar el sistema desde diferentes vistas (casos de uso, diseño, procesos, implementación y despliegue). Ayudan a refinar los casos de uso para identificar nuevos objetos y atributos antes de la codificación.
* **Desventajas:** A menudo son **poco expresivos** tanto para el usuario final (que no puede validar el software solo con planos) como para los desarrolladores, ya que pueden omitir detalles de implementación cruciales. A diferencia de los planos de ingeniería civil, no pueden representar todas las estructuras invisibles y conceptuales del software de forma exhaustiva.
