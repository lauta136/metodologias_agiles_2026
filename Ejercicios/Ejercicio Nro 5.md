# Ejercicio Nro: 5

## Enunciado
**Proponga cinco elementos que ayuden en el desarrollo de software referido a la propiedad de flexibilidad que se requiere.**
**Ejemplo:**
* Diseño para el cambio,
* Ocultamiento de la Información,
* Herramientas de especificación
* Etc.

## Resolución
Cinco elementos que fomentan la flexibilidad son:
1. **Desarrollo Iterativo:** Permite gestionar la incertidumbre mediante ciclos cortos de entrega y ajuste.
2. **Sistema de Control de Versiones:** Imprescindible para mantener todas las versiones entregadas y gestionar la evolución del producto.
3. **Prototipado Rápido:** Ayuda a los clientes a descubrir sus necesidades reales antes de finalizar el diseño.
4. **Contratos Adaptativos:** Donde se fija el coste y el tiempo, pero se permite que el **alcance varíe** de forma controlada.
5. **Refactorización:** Técnica para mejorar la estructura interna del código sin cambiar su comportamiento, facilitando cambios futuros.
