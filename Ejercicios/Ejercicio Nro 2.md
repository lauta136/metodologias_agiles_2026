# Ejercicio Nro: 2

## Enunciado
**¿Qué es para vosotros el desarrollo de software?**
* ¿Ejemplos de desarrollo de software en los que hayas participado? ¿Ejemplos que conozcas?
* ¿Cuál es el papel del desarrollador en el desarrollo de un proyecto software?
* ¿Hay otros papeles importantes en el desarrollo, aparte del desarrollador?
* ¿Cuándo se ha desarrollado un buen software?

## Resolución
He participado en desarrollos para trabajos finales de materias universitarias. El desarrollo de software se define como una **actividad creativa** y no una ingeniería tradicional. El papel del desarrollador es central, pero se complementa con roles como el **analista de sistemas, diseñador de interfaz, arquitecto, ingenieros de componentes y de pruebas**. Se considera que se ha desarrollado un **buen software** (o "software que importa") cuando este resuelve el problema correcto, es **confiable, fácil de mantener** y satisface las necesidades del negocio proporcionando valor real al usuario.
